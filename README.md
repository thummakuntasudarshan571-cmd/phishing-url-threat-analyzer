# phishing-url-threat-analyzer

A simple Python-based cybersecurity project that analyzes URLs for common phishing indicators and classifies their risk level.

## Features

- Analyzes URLs for common phishing indicators
- Checks for suspicious URL symbols
- Checks for unusually long URLs
- Checks for hyphens in the domain
- Calculates a risk score
- Classifies URLs as Low, Medium, or High risk

## Requirements

- Python 3
- urllib.parse (Python standard library)

## How to Run

```bash
python phishing_analyzer.py
